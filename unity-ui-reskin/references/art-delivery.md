# 界面效果图交付规范（给美术）

> 目的：效果图源文件能被工具直接读出「位置、尺寸、字号、颜色、描边、投影、字距」，程序端自动还原，不再靠截图目测反推。
> 依据：战令换皮实测。同一界面用 PSB 源文件对比后，发现目测漏掉了 **按钮字号小 17–20%、标题描边色偏深、三列数字描边色各不相同、标题字距 −30** 等问题。

## 1. 交付物

| 必须 | 说明 |
|---|---|
| **PSD / PSB 源文件**（或 Figma 链接 + Frame） | 每个界面、每个状态一份（或同一文件里用「状态组」区分，见第 4 节） |
| 切图 PNG | 与以前一样；**文件名 = 程序资源名**（英文，例如 `ui_activity_battlepass_button_bg_help.png`） |
| 效果图 PNG | 与源文件同尺寸导出，用于快速预览 |

## 2. 画布

- 画布宽 = 程序 UI 参考宽（多数项目 **768**，以程序告知为准），手机效果图高按项目常用屏高（例 1664 / 1850）；不要额外缩放画布。若习惯在大画布中间放手机画面，四周请用纯色底（工具可自动裁出手机画面）。
- 有 Pad 版设计时，另交一份 **768 × 1024**（4:3）。

## 3. 图层命名（最重要）

| 图层类型 | 命名 | 例 |
|---|---|---|
| 切图对应的图层 / 智能对象 | **与切图文件名一致**（不带 .png） | `ui_activity_battlepass_main_bg_slider` |
| 文字 | 直接用文字内容即可，不用改名 | `Activate` |
| 区块（组） | 区块含义，中英文都行 | `顶栏`、`进度条`、`底部按钮` |

- 不要保留 `图层 838`、`组 8442 拷贝 2` 这类默认名。工具会按名字把图层对到程序里的图片，**默认名的图层只能靠图像匹配，精度和速度都会变差**。
- 同一张切图在界面上出现多次时，可以同名，工具会按位置区分。

## 4. 多状态

- 同一个界面的不同状态（未购买 / 已购买 / 可领取 / 已领取 / 大奖切换…）放在**同名顶层组**里，例如 `状态_未购买`、`状态_可领取`。
- 交付时只打开一个状态组，其余隐藏；工具可以用 `--all-states` 一次性导出全部状态。

## 5. 文字

- **保持文字图层可编辑，不要栅格化、不要转成形状或智能对象。**
- 字体用游戏内字体（现为 `PoetsenOne-Regular`）；字号、字距（Tracking）、行距直接在字符面板里设置。
- 描边 / 投影 / 渐变 / 颜色叠加 **都用图层样式**，不要另外画一层模糊或描边图片。
  - 本项目常用的「实心描边 + 下移 1px」做法：**投影 + 阻塞 100%**，工具可以直接识别。
  - 渐变用「渐变叠加」，角度保持 90°（竖直方向）。
- 用游戏里的真实文案（英文原文）；占位文案请写成和真实文案一样长，否则换行和字号判断会不准。
- 数字类动态内容（倒计时、进度、数量）用典型值即可，工具会把它们当作动态内容处理。

## 6. 图片

- 九宫格拉伸的底图：图层用原始切图拉伸的智能对象，或者在切图文件名后标注九宫格边距（例如 `xxx_9s_40_40_30_30`），方便程序设 border。
- 按钮、面板的阴影和发光如果是切图的一部分，切图里就要包含；如果用图层样式实现，就和文字一样保留在图层样式里。

## 7. 程序侧如何使用（供参考）

```
python -I psd_to_spec.py 效果图.psb --out out/   # 读出全部图层的位置、文字样式 → spec.json + spec.md
python -I diff.py --spec out/spec.json <运行时截图目录> --out diff/   # 与运行时逐项对比，生成修正清单
```

`spec.md` 会列出每个文字图层的字号、颜色、描边、投影、渐变，可以直接拿来核对。
